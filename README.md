# Natural Language SQL Agent

An AI-powered Business Intelligence application that allows users to
ask questions about business data in natural language and receive
results from a PostgreSQL database.

## Features

- Natural language to SQL conversion
- Dynamic PostgreSQL schema detection
- AI-powered SQL generation
- Read-only SQL execution
- SQL safety validation
- FastAPI backend
- Interactive web interface
- Ollama and Groq support
- Environment-variable based configuration
- Professional error handling

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- Ollama
- Groq
- SQL
- HTML
- CSS
- JavaScript
